# SST 模型结构与制作依据

## 概念与范围

按 Anatomy 的 Hero 级要求制作一套可开门、移开外罩的模块化固态变压器柜组。它表示受保护的中压接口、功率电子变换、中频隔离和本地直流接口的概念结构，不复刻未经提供的西比里实物产品，不标称真实容量、真实尺寸、效率或响应时间。

模型采用本项目原生 Three.js 渲染；纯描述模块 `src/sst-model.js` 与渲染适配模块 `src/sst-three.js` 分离，可在园区与数据楼的不同 Three.js 实例中复用。场景坐标为 x 水平、y 向上、z 水平；柜门朝 +z，底面 y=0。含门把手、吊装耳和端子的未缩放柜组外廓约 3.1 × 2.26 × 4.24 个展示单位。

## 交互与结构

- 固定设备、外罩、柜门是三个独立组件。柜门先沿 +z 移出，外罩再向上移开；关闭时按逆序，保持连接端口在底部固定舱。
- 高频/中频隔离用双绕组加闭合磁芯表达；不把工频三相圆柱干变原样复制到 SST 柜内。
- 明亮翡翠绿 `#35c98a` 用在面板、模块锁扣与接口标识；金属、绝缘、磁芯、冷却和母排用可区分的材质。电力流的分类颜色由外层场景维护。
- 机壳拆开后，线束、冷却管和母排留在固定机架上，端头落在本机接口，不随外罩漂移。
- 图中不加真实电压、容量、可维护性、型号与可靠性承诺。文字由外层讲解面板显示。

## 验证方法

纯模型审查覆盖描述数字有效性、正尺寸、组件归属、端口在声明外廓附近、模块功能区之间的外廓分离，以及开门/罩运动方向。它不等同于工程净距校核，也不等同于全部三角形之间的碰撞证明。

本实现是原生三维场景，使用 GPU 深度缓冲，不运行或冒称通过 Anatomy 的 SVG painter-order 与 SVG 线端审计。装配、拆解、中途、近景、手机与明暗场景的视觉核验由园区集成测试完成。功率与损耗由场景的统一仿真模型计算，设备几何本身不产生节能数值。

## 实现与已完成的独立核验

- 高细节版本 641 个实体描述，简化版本 369 个；15 种材质，4 个功能分区，12 条有端部接头的内部路线。高细节版本在支持 InstancedMesh 的 Three.js 中为 43 个批次；这不是完整园区帧率的测量。
- 固定、外罩、柜门三组件；门沿 +z 移出 2.2 单位，外罩后向上移开 4.6 单位。完整展开后的顶部约 8.84 单位，场景镜头应为此留出画面空间。
- Node 纯模块检查：高、简化两版的几何数字、尺寸、功能分区及端口检查通过。Node 不依赖 Three.js，可以单独加载描述模块。
- 使用项目自带 Three.js 的无头浏览器：装配、0.3/0.7 中途与完整展开、内部近景、暗色背景六张截图已逐张阅读，未出现运行时异常。首轮近景后补入了功率单元面板通风槽、锁扣及紧固件，并调整了供回液支路分离和柜底泵安装位置。
- 端口坐标是固定接头的外端面：MV `[-1.55,.68,-.86]`，DC `[1.55,.68,-.86]`，控制 `[1.55,.68,.25]`；连接线应读取 `buildResult.ports`，不按柜体中心猜测位置。
- 单独核验页和截图位于工作区 `tmp/`，仅供制作检查，不作为新的观众入口或修改前后对比页面交付。

适配器 API：`NZ_SST_THREE.build(THREE, {detail:'high'|'simple',scale:1})` 返回 `root`、`groups`、`parts`、`ports`、`dimensions`、`data`、`materials`、`setExplode(t)`、`setHighlight(v)`、`setOpacity(v)`、`audit()`、`dispose()`。动画的时间推进由现有场景负责，适配器不另建渲染循环，不读取园区账本。
