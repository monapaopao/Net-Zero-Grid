# v18 计量与交易字段

|字段|单位/含义|
|---|---|
|runId / scenario|运行唯一标识 / 情景键；重置后新建|
|tasks[].id / key / origin|任务标识、园区、任务来源|
|target / done|目标、实际计入任务的完成量，MWh|
|release / deadline / completedAt|仿真绝对秒；完成前 completedAt 为空|
|missedAtDeadline|是否曾在期限处未完成，不因补产抹除|
|production.remaining / overdue / extra|待完成、其中逾期、额外运行，MWh|
|hydrogen.inventory / target / gap|氢库存、目标库存和缺口，kg|
|meter.tokens|运行累计等效推理 Token；未拆分输入输出|
|meter.itMWh / dcMWh|同周期 IT 电量 / 数据中心总电量|
|meter.dcSourceMWh|按园区混合母线比例分摊到数据中心的来源电量；含未知|
|meter.gridLoadMWh / gridChargeMWh|负荷购电 / 储能购电|
|meter.criticalUnservedMWh|数据中心未供电量；非真实请求失败次数|
|meter.chargingLimitedMWh|充电需求受限电量，不代表可无损延期任务|
|orders[].id / runId|模拟服务需求及所属运行|
|requested / meterStart|预设服务用量、独占计量区间起点|
|quantity / delivered|确认用量、是否确认交付；创建时不自动交付|
|price / amount|元/百万 Token、模拟元；缺价格时 null，不显示为 0 收入|
|status / confirmedAt|模拟流程状态、仿真确认时刻|

GPU·h、数据 GB/调用次数、真实订单和业务电耗分摊尚无数据，仅保留界面框架。能量任务与算力任务不得混加；Token 与交易凭证不是同一对象。
