# 多园区共享综合能源系统 v19 · SST Energy Router

打开 `dist/Net-Zero-grid-premium.html`，选择 **云参观 → 情境演示**。

四个入口为：风光变化，园区如何协同；算力如何跟随绿电；不同策略，会有什么结果；SST 多园区能源路由。前三个主题恢复 v17 的叙事组织，继续使用 v18 调度、任务与计量模块。顶部八种运行工况保持可用。

## SST 参观

六章约 108 秒，可暂停、跳章和重播：全景位置 → 原有设备 → 同址替代 → 楼内结构 → 功率分配 → 结果复盘。楼内加载期间暂停参观计时。

- 数据楼内选定 HVDC 代表支路的隔离降压与整流功能由绿色 SST 模块承担，后端保护、直流配电、后备系统保留。
- 充电站南北两套前端分别切换。原变换单元仅在过渡时显示灰色轮廓；输出保护与充电终端持续保留。
- 主变、开关、光伏逆变器、风机机舱干变、储能 PCS、电解锌均沿用原方案。没有新增储能到 SST 的远距离直流连线。
- 数据楼沿用 10.5 kV 中压输入与 240 V 直流分段输出；充电站沿用 35 kV 柔性交流网络。两个电压等级通过各自保留的主变接入 220 kV 公共网络，不直接短接。复用模型只表达结构类型，不表示同一实物可不经设计在两种中压等级互换。
- 点击北排电源、南排电源或楼内支路可暂停聚焦；点击打开结构／装配复位检查组件。
- 结构阶段的现有／SST 按钮用于装备预览。运行与结果阶段方案状态与 A/B/C 计算保持一致。

模型使用共享纯几何模块 `src/sst-model.js` 与 Three 适配器 `src/sst-three.js`，楼内和园区引用相同结构。精细模型 641 个实体描述，简化模型 369 个。模型的三维遮挡由原生深度缓冲处理，检查使用真实几何及浏览器截图，不将其描述为 Anatomy SVG 审计通过。

独立预览：`dist/数据中心独立预览.html`。它与园区嵌入页都由 `src/vendor/dcdt-v11/` 生成。

当前进入视角为基准。第一次楼层展开平缓旋转一次，后续导览保持方位，通过平移与推进构图；最终收起恢复起始位置、目标和缩放。暂停可手动观察，继续时平缓接回章节。SST 设备局部展示同样保持进入时方向。

2026-10-22 节奏调整：建筑开场至楼层分离为 4 秒；PSU／机柜整体与 CPU/GPU 整体两个过渡合计 2 秒；Cooling 为 4 秒。独立楼内完整导览 77 秒，园区导览的楼内插入段 66 秒，完整园区导览 6 分 09 秒。其余片段各自时长与文案保留。备份在 `backups/v19-before-tour-pacing-20261022/`；字幕与配音时间表随构建同步导出。

独立预览提供原方案／SST 方案和结构展开控制；嵌入时由外层云参观面板控制。窄屏 SST 嵌入采用紧凑视图，隐藏重复工具栏以保留设备画面。

## 运行比较口径

`src/sst-simulation.js` 是隔离的代表性支路仿真，不改动主园区账本。

- IT 输出 5 MW，南北充电代表支路各 1 MW。
- 既有 300 MWh / 150 MW 交流储能中，分配 8 MWh / 3 MW 作为本次演示份额；不是新增电池。
- 2 小时相同天气、相同服务需求、相同初始库存、相同并网限额；1 秒步长。
- A：现有装备与现有调度；B：SST 与相同调度；C：SST 与端口协同规则。
- 现有 IT 支路满载效率基准 97.5%；SST 假设满载 98.0%。固定辅助与负载相关损耗均显式核算，SST 低负载时可以更差。均为可编辑模型中的演示假设，不是西比里产品实测性能。
- 充电功率不为负，没有车辆反向放电。储能通过交流 PCS 调节。并网出口权限、充放电损耗、期末库存、未交付与缺供均记录。
- C 的峰值降低可能伴随更多电池消耗和弃电，不把低购电直接归为节能或最优。
- Token 折算沿用同一 IT 电量系数；每百万 Token 电耗为代表支路的供电输入口径，不含整栋楼制冷，也不代表真实服务交易收入。
- 不计算潮流、短路、电磁暂态、真实控制响应时间或工程可靠性。

第三个原主题“不同策略，会有什么结果”保留受限起点。若方案无法满足保供或期限，执行前会展示约束；可用面板提供的 SOC 55%、购电上限 400 MW 重新推演。不会将不可执行方案显示为通过。
