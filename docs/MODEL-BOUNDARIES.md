# 模型边界与结果解释

本项目用于能源仿真与三维展示，不是现场控制或工程设计软件。

## 园区运行

采用固定一秒物理步长，跟踪功率平衡、储能与氢库存、来源属性、生产任务和服务计量。容量及效率包含演示假设，场景几何和重复工位不等于新增容量或产量。初始库存保持未知来源；能源来源是母线混合分摊示意，不是逐路电表溯源。燃机直接排放参数缺失时，不应将其解释为零排放。

## SST 比较

独立代表支路计算不写入主园区账本：IT 输出 5 MW，南北充电支路各 1 MW，分配既有储能中的 8 MWh / 3 MW 份额。三方案在两小时相同天气、需求、初始库存和并网限额下比较。

A 为现有装备与调度，B 为 SST 与相同调度，C 为 SST 与端口协同。效率是演示假设，不是厂家实测，SST 低负载时可能更差。降低接入点峰值可能伴随更多电池消耗与弃电，应同时比较损耗、期末库存与交付，不能外推全园区。

车辆仅作为充电负荷，不提供 V2G；固定储能经交流 PCS 调节。未开展潮流、短路、电磁暂态或工程可靠性计算。

## 算力与交易

Token 按 IT 用电演示系数折算，不代表真实吞吐、客户交付或收入。模拟订单需要明确确认，不接入支付，也不发行 Token 资产。真实 GPU·h、价格、请求成功率等尚未接入。

## 验证边界

逻辑和原生几何检查验证计算与场景结构，离线检查验证打包和脚本解析。它们不证明浏览器像素、GPU 着色器、帧率或连续播放效果。v20 最新视觉内容仍需实际浏览器验收。
