# v21.1.1 双模式布局

沿用现有白色、深青色、Segoe UI / Microsoft YaHei、窄边框与小圆角，不改三维资产和渲染。此次是已有界面的功能扩展，视觉基线为 v21.0.0。

## 参观（Experience）

顶部保留模式选择并说明“观看园区与协同关系”。左侧保留园区导航，收起柔性调度 HUD；取消常驻右分析栏，扩大三维画面。场景左上提供三分钟路线入口，左下用一行显示原模型的总负荷、可再生电力消费占比和储能 SOC。暂停与倍速仍独立可用。设备卡以介绍、实时状态和进入楼内/查看参数入口为主。标签和流动图层保持原位置。

## 仿真（Operate）

顶部说明“调整条件，观察供需与调度结果”。右侧约 400 px 工作区包含紧凑实时摘要、原有参数/设备/账本/事件/边界来源标签页；默认参数页，其他入口打开对应页。左侧显示柔性调度 HUD，实时指标下方、参数标签页上方展开平衡趋势。设备卡在同一右侧区域显示详细参数，可返回工作区。窄屏工作区改为覆盖下半屏的抽屉，实时摘要可折叠，趋势默认折叠，可在抽屉内展开，顶部模式按钮保持可访问。参观中主动选择情景时进入仿真再应用预设，预设本身的重置行为仍沿用原有逻辑。

## 状态契约

模式仍使用 exhibit/run，单独运行控制仍使用 S.running。切换不重置业务状态、不推进时间、不修改相机位置/目标、参数与库存；画布尺寸随布局更新。导览拥有自身布局，模式栏与新摘要隐藏，退出后恢复保存模式及工作区标签页。只在首次切换/退出导览时打开默认面板，不在每帧强制覆盖用户的面板操作。

## 验收

同机位、同分辨率的两张界面截图；切换前后暂停快照和相机一致；真实参数交互、导出项目版本、标签/光流、SST、接待开始/退出与窄屏无横向溢出。中键问题和额外性能改造不在本轮范围。

## 趋势面板

桌面默认展开，窄屏默认折叠；标题按钮和底部平衡趋势按钮控制同一面板，并分别记住两类屏幕的折叠状态。发电使用橙色 #D97706，负荷使用青绿 #087D73，购电使用紫色 #7C3AED 虚线，弃电使用灰蓝 #64748B，储能使用蓝色 #2563EB。图例保持同色同线型，允许换行。采样仍为每仿真分钟一次、最近 24 点，储能保留绝对值绘制口径。折叠、模式切换和导览退出不清除历史。

运行 node visual-upgrade/webgpu/check-trend.cjs 验证布局、真实画布颜色和虚线、历史与相机连续性及移动端默认折叠。
