# v21.3.0 展厅导览

将 `docs/导览文案/五分钟展厅导览介绍词-v21.2.0-定稿.md` 与 `三分钟快速预览介绍词-v21.2.0-独立修改稿.md` 作为文案源。构建时读取 Markdown，核对接入正文逐字一致；没有重新写一份易失配的口播 JSON。

`content.cjs` 把五分钟稿编为 8 章 / 300 秒、快速预览编为 9 章 / 180 秒。五分钟版在数据中心章节前 28 秒展示园区与供电入口，再以正常速度播放楼内原时间 42–77 秒，保留 2 秒返回观察；三分钟版在全程 70–94 秒插入楼内原时间 50–74 秒。不是整条原路线倍速。

自动字幕以语义标点分页、按文字长度分配显示时长；与章节时钟一起暂停，镜头平滑加减速并保留观察时间。五分钟版和快速预览复用各自已有的状态保存与恢复机制。完成页的重播按钮重播刚结束的路线。

快速预览不再准备和回放旧的“两小时协同推演”或 SST 对比；这两类专题仍可从独立入口进入。导览冻结并恢复进入前的仿真状态，不更改仿真参数来匹配产品介绍的 3.2MW、94–96% 等数字。V2G 为产品接口能力介绍，SMR 仍为研究场景。工厂不再打开工艺屋顶或跟随单根铝线，绿解化工采用现有园区和电解锌镜头，不把现有模型中的其他设备标成合成蛋白设备。

历史 v20 的源文案与运行文件不改写。`build.cjs` 在现有 WebGPU 构建末尾替换外层导览数据和必要的运行行为，不修改楼内独立应用的完整自由参观路线。

```powershell
node visual-upgrade/webgpu/build.cjs
node visual-upgrade/tours/export.cjs
node visual-upgrade/tours/check.cjs
node visual-upgrade/tours/check.cjs --full-play
```

`exports/` 包含与网页一致的讲解稿、CSV 镜头表及 JSON 时间轴。`evidence/` 保存实际播放节点、截图、暂停和状态恢复记录。完整播放检查在精致档、WebGPU、1440×810 / DPR 1 下顺序运行两条路线。

本机完整检查两条路线均遍历全部章节，验证楼内暂停、结束恢复及对应路线重播，无页面错误或外部资源请求。检查记录的墙钟时间包含自动暂停、截图及结束后的状态核对等待，不作为录音时长。另检查 390 px 窄屏字幕及风机、工厂、超充和楼内的稳定机位。

300 / 180 秒为叙述时钟；楼内准备、加载及淡出期间会停住叙述，墙钟时长可能增加数秒。未合成配音，英文缩写与数字的最终朗读节奏仍需录音校准。当前不声称已具备实体工厂实时同步或闭环控制。

回退点：`pre-v21.3.0-tours`（保留两份确认文字及此前网页），原车辆版本标签 `v21.2.0` 继续保留。
