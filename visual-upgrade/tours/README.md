# v21.4.0 展厅导览

将 `docs/导览文案/五分钟展厅导览介绍词-v21.2.0-定稿.md` 与 `三分钟快速预览介绍词-v21.2.0-独立修改稿.md` 作为文案基线，`refinement.cjs` 保存本轮确认的数据中心替换文案、v20 楼内恢复和新的取景安排。当前可核对的完整接入稿、CSV 和 JSON 在 `exports/`，v21.3.0 文件已归入 `exports/archive-v21.3.0/`。

完整园区导览为 8 章 / 347 秒（05:47），快速预览为 9 章 / 268 秒（04:28），均包含末尾 3 秒静止观察。两条路线的数据中心均先用 8 秒介绍园区外景，然后完整播放 99 秒楼内路线，再留 2 秒返回观察。恢复 v20 的 22 个楼内阶段与原字幕，增加进楼提示并替换 HVDC 字幕；将原本各 1 秒的服务器电源、CPU/GPU 机柜阶段延长至各 4 秒，避免相机过渡被截短。

沿用原字幕框样式，优先一次显示同一镜头的完整段落；根据可用宽度，仅在放不下时按完整句子或必要的语义分句分页，不缩小字号。风光与线路采用中远景，电解锌和智能工厂打开顶盖并停留在总览。最后停在大门正面、能看到 xibili 旗帜和远处园区的机位；停留 3 秒后自动回到参观 / 自由探索，保留终场相机，不弹多选面板。中途退出仍恢复进入前相机；两种退出都恢复仿真状态与厂房顶盖。

快速预览不准备和回放旧的“两小时协同推演”或 SST 对比；这两类专题仍可从独立入口进入。导览冻结并恢复进入前的仿真状态，不更改仿真参数来匹配产品介绍的 3.2MW、94–96% 等数字。V2G 为产品接口能力介绍，SMR 仍为研究场景。厂房开顶仅为总览观察，不跟随单根铝线，也不把现有模型中的其他设备标成合成蛋白设备。

历史 v20 的源文案与运行文件不改写。构建时在 WebGPU 内嵌楼内应用中替换时间元数据，保持场景与阶段顺序不变；楼内独立应用也使用一致的平滑阶段时长。
